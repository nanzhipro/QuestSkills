# 出版级 PDF 排版规范

## 1. 字体与字号 (Typography & Size)

- **正文字体**：优先使用 EPUB 内置矢量衬线体 (Serif)。
- **正文字号**：13pt (数字阅读最佳平衡点)。
- **标题字体**：使用无衬线体 (Sans-serif) 或展示体 (Display)。
- **标题字号**：
  - H1: 26pt (居中，强制分页)。
  - H2: 20pt (带装饰线)。
  - H3: 16pt。

## 2. 间距与布局 (Spacing & Layout)

- **行高 (Line Height)**：1.5em (确保阅读流畅性)。
- **页边距 (Margins)**：2.5cm (四周留白，增加呼吸感)。
- **段落间距**：0.8em。
- **首行缩进**：2em。
- **对齐方式**：两端对齐 (Justify)，确保版面整齐。

## 3. 元素处理 (Elements)

- **引用块 (Blockquote)**：左侧 2pt 灰色装饰线，1.5em 缩进，斜体显示。
- **图片**：最大宽度 100%，水平居中，上下留白 1.5em。
- **页码**：底部中央 10pt 灰色字体。

## 4. 技术实现

- **子集化字体嵌入**：通过 `@font-face` 动态注入提取的 `.ttf` 或 `.otf` 文件。
- **安全路径**：使用 MD5 哈希处理超长文件名，防止 CSS 解析引擎崩溃。
