# 金句卡片与视觉分析设计规范

## 1. 核心视觉理念

- **剧照质感**：背景采用原始视频截图，保留访谈的真实场景感。
- **信息分层**：通过渐变蒙层与字体层级，确保在复杂背景下文字依然是视觉重心。
- **品牌符号**：使用特定的红色装饰条与药丸标签，建立项目识别度。

## 2. 金句卡片设计标准

### A. 布局与尺寸
- **画布尺寸**：1280px × 720px (16:9 比例)。
- **对齐方式**：整体采用左对齐布局。
- **安全区域**：核心内容应保持在边缘 80px 的内边距范围内。

### B. 背景处理
- **素材来源**：直接从 720p/1080p 视频源提取的原始帧。
- **滤镜处理**：`brightness(0.6)`。
- **叠层遮罩**：底部 1/3 区域使用从透明到黑色的线性渐变 (`rgba(0,0,0,0)` 到 `rgba(0,0,0,0.8)`)。

### C. 字体与排版
- **字体族**：优先使用 `PingFang SC`, `Microsoft YaHei` 或系统默认无衬线字体。
- **英文金句 (Primary)**：
    - 样式：`38px`, 加粗 (`700`), 斜体 (`italic`)。
    - 颜色：`#FFFFFF`。
    - 特效：左侧配有 `5px` 宽的红色装饰条 (`#ff4d4f`)，并带有轻微光晕。
- **中文金句 (Secondary)**：
    - 样式：`28px`, 常规 (`400`)。
    - 颜色：`#FFFFFF`。
    - 缩进：相对于英文装饰条缩进 `25px`。

### D. 页脚元素
- **位置**：距离底部 50px，左对齐。
- **标签 (Tag Pill)**：
    - 背景：`#ff4d4f`，圆角 `3px`。
    - 文字：白色，`14px`，全大写，字间距 `0.5px`。
- **标题 (Video Title)**：
    - 样式：`16px`，白色，不透明度 `0.9`。

## 3. 战略金字塔设计标准

### A. 颜色系统
- **核心层 (WHY)**：红色 (`#ff4d4f`) - 代表核心驱动与本质。
- **方法层 (HOW)**：蓝色 (`#40a9ff`) - 代表路径与执行。
- **成果层 (WHAT)**：绿色 (`#73d13d`) - 代表产出与影响。

### B. 交互与质感
- **圆角**：容器圆角 `24px`，层级圆角 `12px`。
- **阴影**：外层容器采用大范围柔和阴影 (`0 20px 50px rgba(0,0,0,0.1)`)。
- **动态感**：鼠标悬停时层级应有轻微上浮效果 (`translateY(-5px)`)。

## 4. 技术实现规范

### A. 工具链
- **截图**：FFmpeg (用于原子化帧提取)。
- **渲染**：Playwright (基于 Headless Chromium 的 HTML 渲染)。
- **资产转换**：Canvas/Screenshot (高质量导出 JPEG/PNG)。

### B. 渲染流程
1. **原子化提取**：使用 FFmpeg 提取 `raw_temp.jpg`。
2. **Base64 转换**：将图片转为 Base64 字符串直接嵌入 HTML。
3. **DOM 注入**：将金句文本与图片注入预设的 HTML/CSS 模板。
4. **延迟截屏**：`waitForTimeout(1000)` 确保 WebKit/Blink 引擎完成字体渲染。
5. **文件覆盖**：直接覆盖原始截图，保持 Markdown 引用链接持久有效。

## 5. 内容策略

- **金句筛选**：每期视频筛选 5-7 条具备高度传播价值的独立观点。
- **长度控制**：单条金句建议不超过 3 行，确保视觉美感。
- **翻译准则**：中文翻译应兼顾“信、达、雅”，在保持原意基础上进行口语化润色。
