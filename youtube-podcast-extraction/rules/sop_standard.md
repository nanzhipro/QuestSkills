# YouTube 播客提取标准作业程序 (SOP)

## 1. 核心目标

通过标准化的前置检查、数据提取、翻译分析及可视化渲染，确保播客内容知识的高效沉淀与传播。

## 2. 进度状态规范

每个阶段执行时，必须输出明显的状态标识：

- **📍 阶段 N/4：[阶段名称]**
- **✅ 阶段 N 完成：[简要说明产出]**
- **❌ 阶段 N 失败：[错误原因]**

## 3. 四阶段 SOP 流程

### 阶段 1：数据准备 (Data Preparation)

- **下载资产**：使用 `yt-dlp` 获取视频标题、下载 VTT 字幕及视频文件。
  - **可靠性建议**：若默认下载缓慢或失败，优先尝试 `-f 18` (360p MP4) 或 `-f "best[height<=720][ext=mp4]"` 以确保快速下载且无需复杂合并。
- **清洗文本**：调用 `clean_subs.py` 脚本执行词窗重叠去重。
- **产出**：`transcript_en.txt`, `timestamp_map.json`, `video.mp4`。

### 阶段 2：深度分析 (Deep Analysis)

- **三档处理逻辑**：
  - **短视频 (Short, <10m)**：采用“原文结构化翻译”模式，确保内容完整性。
  - **中长视频 (Medium, 10-30m)**：采用“高保真提炼 (60%)”模式，兼顾细节与易读性。
  - **超长视频 (Long, >30m)**：采用“战略级提炼 (40%)”模式，按章节深度拆解。
- **翻译与提炼**：生成核心提炼文档 `transcript_zh.md`。
  - **金句保留**：关键金句部分必须保留英文原文（直接使用 `> ` 引用块，不带显式标签），以便后续视觉回填。
- **架构分析**：执行金字塔原理分析，生成 `pyramid_analysis_zh.md`。
- **提取金句**：从分析文档中提炼 5-7 个核心金句，存入 `quotes_list.json`。

### 阶段 3：资产生成 (Asset Generation)

- **卡片渲染**：运行 `generate_quotes_pro.js` 生成电影感金句卡片。

### 阶段 4：成果交付 (Delivery)

- **文档回填**：将生成的金句图片路径回填至 `pyramid_analysis_zh.md` 和 `transcript_zh.md`。
  - **预览要求**：确保在 Markdown 文档中能直接预览美化后的金句图片，增强阅读体验。
- **文案适配**：生成多平台发布文案 `publish_content.md`。
- **清理工作**：删除临时 VTT 及大型视频文件（除非另有说明）。

## 4. 质量红线

1. **禁止 ImageMagick**：金句卡片必须通过 Playwright 渲染。
2. **禁止 Emoji**：所有交付文档（Markdown/HTML）严禁出现 Emoji。
3. **逐字一致**：金句英文必须与字幕原文 100% 匹配。
4. **清理规范**：任务完成后必须清理中间大型文件。
