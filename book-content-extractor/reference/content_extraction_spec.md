# 专业书籍核心内容萃取规范 (V1.0)

## 1. 视角与目标 (Perspective & Objectives)

本规范旨在从**专业萃取专家**的视角，通过标准化、可量化的方法论，将专业书籍中的冗余信息剔除，精准提炼出 **50% 的核心高价值内容**。

- **核心目标**：在不遗漏关键逻辑和结论的前提下，将阅读时间成本降低 50%，同时最大化保留书籍的“血肉”与细节。
- **萃取原则**：逻辑完整、观点明确、细节丰富、数据驱动。

---

## 2. 核心观点提取方法论 (Extraction Methodology)

萃取过程遵循“结构-逻辑-细节-行动”四层过滤模型。

### 2.1 结构过滤 (Structural Filtering)

- **目录解析**：识别书籍的骨架，区分“基础理论区”、“核心方法区”与“案例补充区”。
- **篇章权重分配**：根据书籍类型（如商业管理、心理学、技术手册），预先分配 50% 的容量配额给核心篇章。

### 2.2 逻辑萃取 (Logical Distillation)

- **费曼主线 (Feynman Main Line)**：洞察全书的逻辑基石，构建一条能够使用费曼学习法向他人讲解的逻辑主线。
- **概念 (Concept)**：提取书中定义的关键术语和新颖模型。
- **推导 (Inference)**：记录作者从现状到结论的逻辑转折点。
- **金句 (Golden Sentences)**：高度概括作者核心思想的原创性陈述。

### 2.3 费曼主线构建指南 (Feynman Main Line Construction Guide)

为了让萃取内容具备极强的可传播性与逻辑性，必须遵循以下构建规范：

1. **逻辑闭环**：主线必须具备“起、承、转、合”的严密逻辑。从一个普通人能理解的起点（痛点或常识），通过逻辑推导，最终导向书中的核心方案。
2. **节点串联**：将书中分散的“珍珠”（观点、数据、故事）穿在这条主线上。每一个节点必须是主线演进的必然步骤，杜绝孤立存在的知识点。
3. **通俗化转换**：主线的描述必须通过“类比”或“简化”，使其达到能够向 10 岁孩子讲清楚的程度。
4. **主线架构图**：必须使用结构化列表或流程图形式展示这条逻辑路径。

### 2.4 行动转化 (Actionable Conversion)

- **SOP 化**：将书中的理论转化为可执行的步骤或清单。
- **应用场景**：明确该核心观点在什么情况下适用，什么情况下不适用。
- **串联任务**：将书中分散的洞察、故事和工具，像珍珠一样穿在这一条逻辑线上，形成一套完整的“故事方案”。

### 2.5 高价值内容钩子 (High-Impact Content Hooks)

为了增强笔记的记忆深度与传播力，必须强制提取以下“内容钩子”并挂载到“费曼主线”上：

1. **反常识观点 (Counter-Intuitive)**：挑战常规认知、令人意外的结论。
2. **瞠目结舌的数据 (Shocking Data)**：支撑核心论点、具备极强说服力或冲击力的关键数据。
3. **情绪故事 (Emotional Stories)**：能够调动读者情绪、具备极强代表性且让人记忆犹新的案例。
4. **关键人物 (Key Figures)**：书中提及的灵魂人物、权威专家或典型案例主角。
5. **隐性洞察 (Hidden Insights)**：那些容易被忽视，但一旦理解后对全局有重大影响的观点。

### 2.6 情感化价值合成 (Emotional Value Synthesis)

萃取的终点不仅是逻辑，更是触达。必须站在“向最亲近的人推荐”的视角，合成一段推荐语：

- **核心要求**：200 字以内。
- **情感基调**：真诚、有力、具备极强的“获得感”。
- **合成公式**：`[痛点共鸣] + [核心方案/洞察] + [具体获得感/改变]`。

## 3. 50% 核心内容量化标准 (Quantifiable Standards)

为确保精准控制在 50% 左右的容量，采用以下量化指标：

| 内容类别           | 权重 | 提取标准                                                                  |
| :----------------- | :--- | :------------------------------------------------------------------------ |
| **费曼主线逻辑**   | 100% | 主线必须涵盖“背景-核心矛盾-解决方案-演进路径”，且每个环节逻辑严密、顺畅。 |
| **高价值内容钩子** | 100% | 反常识、冲击性数据、情绪故事、关键人物及隐性洞察需精准保留并关联至主线。  |
| **关键结论**       | 100% | 每一章的论点、论据及推导过程需完整保留，确保逻辑链条不断裂。              |
| **方法论/工具**    | 80%  | 具有普适性的操作流程、工具表单、检查清单及配套的解释说明。                |
| **案例/背景**      | 30%  | 保留典型案例的完整叙述（起因-经过-结果），不仅是概要。                    |

**量化计算公式**：
`萃取率 = (萃取后字数 / 原书总字数) × 100%`。目标范围：45% - 55%。

## 4. 质量控制标准 (Quality Control)

每份萃取文件需通过以下六维度的验证：

1. **准确性 (Accuracy)**：
   - 是否存在曲解作者意图的情况？
   - 关键术语引用是否与原书一致？
2. **完整性 (Completeness)**：
   - 书中的核心逻辑链条（Why-What-How）是否闭环？
   - 是否遗漏了作者在序言或结语中强调的“唯一关键点”？
3. **独立性 (Independence)**：
   - 萃取后的内容是否可以在不翻阅原书的情况下被专业读者理解？
4. **费曼主线质量 (Feynman Logic)**：
   - 是否能够仅凭“主线逻辑”在 5 分钟内向他人讲清楚全书核心？
   - 逻辑节点之间是否存在跳跃或断层？
5. **语言纯净性 (Language Purity)**：
   - **严禁中英混杂句**：完整的正文叙述必须使用纯粹的中文表达，不得在中文句子中夹杂英文单词。
   - **保留必要英文**：核心概念 (Concept)、专有名词 (Term)、关键语句引用、书名/标题、人名允许且必须保留英文。
   - **结构化处理**：如需同时展示中英文，应使用括号 `中文 (English)` 形式，而非在语序中混用。
6. **简洁度与触达力**：
   - 是否存在冗余描述？“至亲推荐语”是否具备极强的价值触达力？

## 5. 实施流程 (Implementation Process)

- 耗时：约 10%

### 第一阶段：全景扫描 (Survey)

### 第二阶段：结构拆解 (Deconstruction)

- 耗时：约 20%
- 动作：按照“核心观点”与“辅助信息”对全书进行标注（如使用不同颜色的高亮）。

### 第二阶段：逻辑建模 (Logic Modeling)

- 耗时：约 50%
- 动作：寻找全书的“灵魂红线”，构建**费曼讲解主线**。确保所有核心内容（钩子、结论、工具）都能逻辑严密地挂载到这条线上。
- 动作：编写“至亲推荐语”，确保其基调与主线一致。

### 第三阶段：精细萃取 (Distillation)

- 耗时：约 20%
- 动作：按照第 2 章的方法论，编写核心内容。遵循“删除-压缩-合并”原则。
- 动作：使用“量化计算公式”检查是否符合 50% 比例要求。

### 第四阶段：验证与优化 (Validation)

- 动作：对照第 4 章的质控标准进行自查，重点检查“费曼主线逻辑”的严密性。

## 6. 交付物结构 (Deliverable Structure)

1. **文件名**：`《书名》 - 核心萃取笔记.md`
2. **基本信息 (Meta Info)**：在笔记最开头，列出书籍基本元信息：
   - **作者**：[作者姓名]
   - **作者简介 (About the Author)**：[需通过联网搜索补充：作者的身份、头衔、杰出贡献、核心成就、业界评价等]
   - **出版年份**：[年份]
   - **核心主题**：[1-3个关键词]
   - **原书容量**：[页数/字数概估]

3. **核心价值 (Core Value)**：
   - **至亲推荐语 (The Best Recommendation)**：200字以内，极具力度的价值概括。
   - **一句话核心价值 (The One Thing)**

4. **费曼讲解主线 (Feynman Main Line)**：
   - **主线描述**：使用“背景 -> 矛盾 -> 方案 -> 路径”的结构化叙述。
   - **逻辑节点图**：使用 Mermaid (如可用) 或 Markdown 列表展示逻辑演进过程。

5. **高价值洞察 (High-Impact Insights)**：
   - 挂载在主线上的反常识观点、冲击性数据、情绪故事、关键人物、隐性洞察。

6. **核心章节深度萃取**：
   - 包含关键结论、方法论/工具，保留 30% 的典型案例细节。

7. **行动建议清单 (Action Items)**：
   - SOP 化的步骤、应用场景。

8. **排版**：遵循标准 Markdown 语法排版，确保结构清晰、易于阅读。
